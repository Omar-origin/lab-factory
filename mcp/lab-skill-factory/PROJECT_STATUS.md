# Lab Factory v2 项目状态

更新时间：2026-07-13
当前阶段：v2 核心技术原型已完成，正在进入真实模板校准与 WPS 内测阶段。

## 产品定位

Lab Factory v2 是一个可靠的 DOCX 模板编译器：首次学习一门课程的模板结构、写作规则和用户偏好，之后在不破坏源文件和非目标区域的前提下，稳定生成位置正确、格式安全、风格有差异的实验报告草稿。

当前目标是支持 10–20 位真实用户在没有开发者陪同的情况下完成报告。支付、云同步、通用 GUI 和商业化不在本阶段范围内。

## 已实现

### DOCX 模板编译与安全写回

- 直接解析 DOCX OOXML inventory，覆盖正文、表格单元格、页眉页脚、样式、编号、上下文和图片关系。
- 为可写位置生成稳定 `node_id`，保存结构路径、表格行列坐标、上下文指纹和样式来源。
- 文本框、公式、域和修订等复杂对象标记为 `unsupported`，禁止静默写入。
- 使用模板家族指纹、容器类型、上下文、结构、样式和候选唯一性进行定位评分。
- `auto` 要求分数至少 0.90 且领先第二候选至少 0.15；`confirm` 必须由用户选择；`blocked` 禁止写入。
- 使用 `python-docx + lxml/OOXML` 最小修改生成副本，验证源文件不变及非目标 DOCX 部件哈希不变。
- 支持段落插入、占位符替换和表格单元格写入，并输出写入审计信息。

### 受控工作流

- 已实现持久化状态机：

  ```text
  materials_scanned
  → requirements_confirmed
  → placements_resolved
  → content_ready
  → draft_generated
  → draft_reviewed
  → finalized
  → iteration_decided
  ```

- 会话保存 `session-state.json` 和审计日志，可以在客户端中断后恢复。
- 需求未确认不得生成草稿；低置信度定位未解决不得写入；草稿未经用户审阅不得 Finalize。
- 草稿审阅记录 `review_id`、用户决定和反馈摘要。
- 终稿后提供继续修改、审阅 Skill 更新 diff、完成但不更新三个出口。
- Skill 更新经过隐私门禁，排除姓名、学号、样本正文、当前报告正文和一次性异常。

### 差异化与防照抄

- 支持课程写作画像、四维写作参数和预设。
- 支持不保存样本正文的 `style-card.json`。
- 每份报告保存 `variation_seed`，同一报告修改时保持风格稳定。
- Finalize 前执行连续重复文本、句子相似度和字符 5-gram 三类检查。
- 相似性门禁失败会阻止 Finalize，不允许 Agent 绕过。

### 接口、兼容与分发

- MCP Server 已升级为 v0.2.0，并提供 inventory、模板配置、定位确认、会话、草稿审阅、Finalize、写作画像、风格卡、v1 迁移和 Skill 更新接口。
- CLI 已增加对应 v2 命令。
- v1 Fill Map 仅保留读取和迁移能力；旧字符串锚点必须重新定位。
- 专属课程 Skill 脚手架、Schema、验证器、使用文档和 macOS/Windows 构建脚本已更新。

## 尚未完成或尚未证明

### 真实模板准确率

- 尚未建立至少 10 份脱敏真实 DOCX 的黄金测试集。
- 尚未人工标注正确写入节点和不可修改区域。
- 尚未校准定位评分和相似性阈值。
- 因此尚不能声称高置信度定位准确率达到 99%，也不能声称自动覆盖率达到 70–80%。

### WPS、Windows 与真实用户

- 尚未完成 Windows/macOS WPS 上至少 10 个真实模板的写入前后验收。
- 尚未完成 WPS 打开、保存、再次解析的往返测试。
- Windows 构建脚本已经更新，但尚未在 Windows 实机上构建和验证成品。
- 尚未完成 10–20 位用户的正式内测及任务指标收集。

### 差异化效果

- 写作画像、风格卡、变化种子和相似性门禁已经实现，但尚未完成多用户、多种子输出差异评测。
- 尚未证明最终输出在保持事实准确的同时足够不同。
- 风格卡由宿主 Codex/Claude Code 从参考材料生成；当前引擎负责 Schema 校验和正文泄漏拦截，不负责独立理解任意参考报告。

### 有意保留的安全边界

- 文本框、复杂公式、域、修订、部分浮动图片和复杂嵌套表格暂不自动写入。
- 视觉一致性仍需用户在最终使用的 Word/WPS 环境中确认。
- `docxtpl` 只用于 Lab Factory 控制的标准占位模板，不作为任意老师模板的默认引擎。

## 发布判断

当前可以作为内部开发版和受控测试版使用，但不应宣称已经达到生产级、支持所有复杂 DOCX，或已经满足 99% 定位准确率。进入下一发布阶段的前提是完成真实黄金测试集、WPS 双平台验收和真实用户指标收集。
