# Lab Factory 用户使用说明

Lab Factory 的作用是：读取实验报告模板、任务书和课程要求，帮助你定制一个对应课程的实验报告 skill。之后由这个专属 skill 辅助整理材料、生成填补草稿、保留模板格式、提示截图位置，并在你确认后整理终版。

它不是直接代写工具。生成内容仅供学习参考，请自行核验实验数据、截图、代码和课程要求。

## 一、部署

1. 下载与你系统对应的压缩包：
   - Windows：`lab-factory-windows-x64.zip`
   - Apple Silicon Mac：`lab-factory-macos-arm64.zip`

2. 不需要自己研究配置命令。直接把压缩包的本地路径发给 Claude Code 或 Codex：

   ```text
   请帮我部署这个：
   <压缩包的完整路径>
   ```

   压缩包根目录已经放置 `INSTALL_FOR_AGENT.md`。Agent 解压并查看文件后，会自动读取这份部署入口。只有 Agent 没有主动查看压缩包内容时，才需要补充一句：“请先阅读压缩包根目录的 `INSTALL_FOR_AGENT.md`。”

3. Agent 会完成以下操作：
   - 解压压缩包；
   - 找到 `lab-factory` 或 `lab-factory.exe`；
   - 检查运行环境；
   - 写入 Claude Code 或 Codex 的 MCP 配置；
   - 运行 `mcp-smoke` 验证连接；
   - 告诉你是否需要重启 Claude Code 或 Codex。

## 二、授权或激活

### 免费内测

如果没有收到激活码和授权服务地址，让 Agent 使用免费内测模式：

```text
我没有激活码，请按免费内测方式部署，使用 --dev-allow。
```

Agent 会重新执行安装并把免费内测授权写入当前客户端配置。该方式只适合测试版。

### 激活码模式

如果你收到了激活码，同时应当收到一个授权服务地址。把两者一起交给 Agent：

```text
请帮我激活 Lab Factory。
授权服务地址：<https://...>
激活码：<你的激活码>
```

Agent 会配置授权地址、完成激活并再次检查状态。激活码不要发到公开群聊或提交到 Git 仓库。

## 三、第一次使用（v2）

部署和授权完成后，在 Claude Code 或 Codex 中输入：

```text
请使用 lab-skill-factory。
这是我的实验报告模板：<模板完整路径>

请先从头到尾完整阅读文档，复述实验目的、任务要求、提交要求、
文件命名要求和必须使用的软件或环境。
然后一次只问我一个关键问题。
需求没有确认完整之前，不要开始生成专属 skill，也不要开始写实验报告。Lab Factory 会先集中展示已经从材料中识别出的要求，只追问缺失或冲突项。
```

建议同时提供：

- 实验报告模板或任务书；
- 老师发布的格式和提交要求；
- 同科目参考报告，只学习结构、篇幅和排版；
- 源码、真实数据和已有截图；
- 个人信息与文件命名规则可在 Agent 需要时再提供。

## 四、生成专属课程 Skill

Lab Factory 会在确认需求后生成一个用户可见、可编辑的专属课程 skill。生成后先检查：

- 课程和模板适用范围是否正确；
- 哪些部分允许填写；
- 哪些原文、结构和格式禁止修改；
- 字体、字号、行距和字数要求是否正确；
- 必须使用的软件、代码环境和截图要求是否完整。

发现问题时直接告诉 Agent 修改，不要在规则有误时继续生成报告。

## 五、调用专属 Skill

以后做同一门课程的实验时，可以直接说：

```text
请使用我的 <课程名称> 专属实验报告 skill 处理这个实验：
<新实验模板或任务书路径>

先完整阅读并复述要求，再询问需要确认的信息。
请使用 v2 模板配置。高置信度位置可以自动使用；低置信度位置先把候选上下文和表格坐标给我选择；blocked 位置不要写入。
第一次只生成草稿，不删除模板原文，不修改未确认区域。
```

如果 Agent 没有自动找到 skill，可以同时提供专属 skill 的文件夹或 `SKILL.md` 路径。

## 六、草稿和终版

第一次草稿遵循“只填补、不删改”，并要求在 WPS 或实际编辑器中检查：

- 不删除模板原文；
- 不修改未确认的区域；
- 需要截图或现场操作的地方保留占位提示；
- 无法证明是真实结果的数据不会伪装成真实数据。
- 写入位置、表格边框与合并、分页行距、图片和公式位置。

你检查草稿并补充截图、数据或个人信息后，再说：

```text
我已经补充完成，请进行第二次整理。
只删除我确认可以删除的提示内容，调整排版，添加免责声明并生成终版。
```

终版完成后有三个选择：继续修改、查看更新差异并确认迭代专属 Skill、完成但不更新。系统不会强迫更新，也不会把姓名、学号、样本正文或当前报告正文写入 Skill。

如果提供参考成品，系统只保存结构化风格卡。终稿必须通过防照抄检查；命中长连续文本、多个高度相似句子或过高 5-gram 重合时，需要先重写。

## 七、常见问题

### 提示未激活

让 Agent 运行 `status`。如果提示没有授权方式：

- 免费内测：重新执行 `install --dev-allow`；
- 激活码模式：同时提供激活码和授权服务地址。

### macOS 提示无法验证开发者

免费测试版尚未完成 Apple Developer ID 签名和公证。确认文件来源可信后，让 Agent 按 `INSTALL_FOR_AGENT.md` 处理 quarantine。

### Windows 提示 SmartScreen

免费测试版尚未进行 Windows Authenticode 签名。只应运行可信来源的安装包。
