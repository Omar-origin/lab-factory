THREE STEPS

从 ZIP 到宿主里的 Lab Factory

  1. 选择系统并校验下载对应 ZIP 和 SHA-256 清单。校验不匹配就停止，不运行包内文件。
  2. 把 ZIP 导入本机 Agent给它读取压缩包、执行本机命令、写入你选择的 MCP 配置的权限。
  3. 告诉 Agent 按说明安装它会按包内步骤安装、保留其他 MCP 配置、运行诊断并告诉你是否需要重启宿主。
可以直接对 Agent 说

请先阅读这个 ZIP 根目录里的 INSTALL_FOR_AGENT.md，按其中步骤为我安装 Lab Factory。安装前核对 SHA-256；只修改我实际使用的 MCP 宿主配置，保留其他服务器；完成后运行诊断并告诉我如何重启宿主。不要索要或代填授权密钥。

CLIENT SETUP

不同 Agent 的连接方式

  • Codex、Claude Code：命令可自动合并 MCP 配置。
  • WorkBuddy、Kimi：按宿主提供的 stdio MCP 配置格式合并；具体配置入口由你当前的 Agent 版本决定。
  • DeepSeek 等模型：模型本身不等于本地 Agent；需要运行在能访问本机文件和 stdio MCP 的宿主中。

BETA / SIGNING

首次运行前请留意

这批 Beta 构建尚未使用 Windows 代码签名证书或 Apple Developer ID 签名/公证。Windows 可能显示 SmartScreen 提示，macOS 可能显示 Gatekeeper 提示。先对照官方 Release 的 SHA-256；若系统仍阻止运行，按包内说明停下并由你本人确认系统提示。
