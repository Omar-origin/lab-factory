# <课程名> 实验报告专属 Skill

## 使用边界

本 skill 只服务当前用户的 <课程名> 或同类实验报告流程。它记录被用户确认过的稳定流程规则，不代表所有学校或所有老师的要求。

如果当前任务与这些规则不匹配，使用 `universal-lab-report` 重新清点材料并生成报告。

## 触发词

- <课程名>
- <实验简称>
- <老师或模板的非隐私描述>
- <常见实验类型>

## 稳定流程规则

- 任务书优先，模板控制格式。
- 草稿版保留截图占位和用户待办。
- 用户补齐后再 finalize。
- 文末保留免责声明。

## 已确认格式偏好

- 正文：<字体、字号、缩进、行距>
- 图注：<图注格式>
- 小结：<问题、心得、建议结构>
- 截图提示：<截图占位风格>

## 常见实验结构

1. <章节或任务类型>
2. <章节或任务类型>
3. <章节或任务类型>

## Finalize 清理规则

- 删除用户操作指导。
- 删除草稿状态说明。
- 删除未确认保留的截图占位。
- 保留参考示例正文标注和免责声明。

## 迭代日志

每次用户确认满意后，追加：

```text
日期：
实验类型：
用户确认满意的点：
新增规则：
不应泛化的特殊情况：
```
