# 标准输入文件夹模板

用户不必须使用这个结构，但使用后更容易让 agent 自动识别材料角色。

```text
实验任务书/
实验所需文件/
实验报告模板/
成品实验报告/
实验相关课件/
实验原始数据.md
个人信息.md
评分标准.md
输出文件要求.md
目标写作风格.md
```

空目录和空 `.md` 文件可以保留。skill 会跳过空内容。

## 建议填写

`实验原始数据.md`：

```text
把真实实验数据、日志、运行结果、测量记录或截图说明放在这里。
没有真实数据时留空。
```

`个人信息.md`：

```text
姓名：
学号：
班级：
课程名：
指导教师：
日期：
```

`输出文件要求.md`：

```text
输出格式：
命名规则：
输出位置：
是否需要草稿版和最终版：
```

`目标写作风格.md`：

```text
例如：普通本科生实验报告风格，语言自然，步骤详细，分析不要太像论文。
```
