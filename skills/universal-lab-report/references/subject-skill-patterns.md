# Subject Skill Patterns

## 目的

本文件提炼已有科目专属实验报告 skills 的通用成功模式。不要把某一门课的内容硬编码进通用 skill；要学习它们为什么能精确满足报告模板。

## 共性模式

### 1. 明确分工

科目 skill 会先定义谁做什么：

- agent 读要求、填模板、留截图占位、调格式。
- 用户补截图、补个人信息、完成外部软件操作。
- agent 在用户回来后做二次清理。

通用 skill 也必须保持这个分工，不能试图一次性完成用户必须亲自完成的部分。

### 2. 先读任务，再判断类型

科目 skill 不会一开始就写正文，而是先读任务书并判断实验类型：

- 软件工程：判断类图、时序图、部署文档等内容类型。
- 人工智能：拆分大任务、小点、数据文件和 Notebook 单元。
- 组成原理：判断 Logisim 还是 MASM/DOSBox。
- 计算机网络：判断命令、服务器、本地 Wireshark 或协议分析。

通用 skill 应先抽象出实验类型和内容类型，再决定填写策略。

### 3. 填写范围很窄

科目 skill 的输出稳定，是因为只填明确区域：

- 组成原理只生成“五、实验步骤”和“六、实验小结”。
- 网络实验只生成结果分析和截图说明，第二遍再清理命令。
- AI 报告按任务步骤插入正文、图注和小结。
- 软件工程按模板占位填图文说明和截图占位。

通用 skill 必须先列出可填写范围。未确认区域保持原样。

### 4. 模板锚点决定插入位置

稳定做法不是整篇重写，而是：

- 找到占位段落。
- 找到目标章节标题。
- 找到表格单元格。
- 在锚点后插入或局部替换。

尤其 DOCX 里要避免把内容追加到文档末尾，或塞进第一个大表格单元格。

### 5. 样式显式设置

科目 skill 会写明字号、字体、颜色、图注、缩进等，因为模板占位文字可能带红色、蓝色、下划线或错误样式。

通用 skill 应复用模板样式，并在新增正文中显式设置必要格式，避免继承占位提示样式。

### 6. 两遍流程

第一遍：

- 生成草稿。
- 留截图占位。
- 保留用户待办。
- 不强行清理。

第二遍：

- 用户补图后回来。
- 确认删除范围。
- 清理提示。
- 统一格式。
- 填封面和文件名。

通用 skill 不能把草稿版和最终版混成一次操作。

### 7. 可复用规则沉淀

专属 skill 应沉淀的是：

- 触发词。
- 常见章节。
- 锚点定位方式。
- 截图占位格式。
- 小结结构。
- finalize 清理规则。

不要沉淀用户隐私、完整报告正文或一次性实验数据。
